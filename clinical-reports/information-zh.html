当前真实能力

以下只来自当前仓库 SKILL.md、scripts、assets 与 references，并严格区分结构辅助、确定性检查与必须由专业人员承担的判断。

01

报告类型路由

CARE 2013、CONSORT 2025、SPIRIT 2025、ICH E3/E3 Q&A，以及 aggregate safety 等路径被明确区分。

02

15 个 fail-closed 模板

生成器只复制固定 JSON/CSV asset；不插值、不自动补临床事实、不默认覆盖已有文件。

03

确定性结构检查

CARE、ICH E3、CONSORT 2025 与 SPIRIT 2025 的键、状态和 source-fact 引用检查。

04

来源与一致性

检查 local locators、SHA-256 元数据、claim links、日期、单位、n/N 百分比和 totals；不选择“正确来源”。

05

聚合 AE 表格

仅接受聚合 rows 与 sidecar metadata；拒绝 patient/subject/case identifiers、narratives 与 onset dates。

06

有边界的辅助检查

术语只做 schema/syntax 或本地词典 exact match；去标识化脚本只检查流程记录。Radiology / pathology / lab 是 field-map scaffold。

安全工作流

unsupported content remains missing。脚本不打开患者叙述、不调用外部模型、不做临床或监管决策。

01 · ALLOWED DATA

Synthetic / de-identified / aggregate facts；目的、授权、minimum necessary 明确。

02 · INPUT GATE

不满足边界就停止；真实 PHI 不进入示例、日志或外部服务。

03 · PROVENANCE

local locator + field path + value hash + verifier role/date。

04 · ROUTING

按 artifact 选择 CARE / CONSORT / SPIRIT / ICH E3 / aggregate route。

05 · FAIL-CLOSED

模板以 BLOCKED / missing / null 起步，不自动补齐。

06 · VALIDATION

结构、引用、schema、arithmetic 与 process documentation。

07 · HUMAN REVIEW

合格临床、统计、安全、隐私/法律、QA、监管或作者复核。

A successful validation result does NOT replace qualified review.

六次运行，三个工作流

中文 3 次 + 英文 3 次分别执行并保存。底层确定性脚本在 schema 相同时可能输出相同状态；每个语言版本的 prompt、input、commands、artifacts 与 logs 均独立落盘。

只用已验证的 synthetic source-fact ID 覆盖 CARE 结构；没有来源支持的项目继续保持 missing。
