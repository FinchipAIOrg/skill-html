Core capabilities

代码当前真正支持的能力

依据当前仓库 v3.9.4、投资者数据库与 evaluator 结构整理；人数与流派以代码为准，而非历史文档标题。

01 / MULTI-METHOD

66 个方法论角色

每个角色有自己的关注字段、规则与参考来源；角色输出是方法论模拟，不是本人实时观点。

02 / STRUCTURED

结构化 Signal

单个角色可输出 signal、score、confidence、verdict 与 comment，便于比较和后续报告组装。

03 / SCHOOLS

9 大流派归组

经典价值、成长、宏观、技术、中国价投、A股游资、量化、科技领袖与 AI 卡位猎手。

04 / CONSENSUS

共识与信号分布

聚合长仓口径信号，展示 bullish / neutral / bearish 分布与共识分；做空观察角色单独保留。

05 / CROSS-MARKET

跨市场输入

工作流面向 A 股、港股与美股；实际数据完整度取决于数据源连通、标的与可选 API 配置。

06 / TRACEABLE

缓存与可追溯输出

研究过程可生成 raw_data、dimensions、panel、synthesis 与 HTML report 等阶段性文件。

How it works

从数据到评审结论

数据先被采集和标准化为分析维度，再进入角色规则与评分流程。输出既保留个体差异，也生成聚合视图。

01

Market & Company Data

行情、财务、估值、行业、事件、资金与情绪等可用数据。

02

Dimensions

把异构数据整理成 evaluator 可消费的结构化维度。

03

Methodologies

各角色只读取与其方法论相关的字段并执行规则评估。

04

Signals

生成个人 signal、score、confidence、verdict 与 reasoning。

05

Panel Review

汇总分布、流派差异、共识与完整研究报告。

关键边界：面板角色是在既定方法论与规则下进行的研究模拟。页面中的“巴菲特式”“索罗斯式”等表达指方法论视角，不代表相关人物对该股票的实际、当前意见。

Reliability & limitations

知道它能做什么，也知道不能做什么

金融研究工具的可信度，不只来自输出丰富，更来自对数据、方法与角色边界的清楚说明。

Methodology boundary

这是一套研究辅助与方法论模拟系统

角色名称用于帮助用户理解不同投资框架。任何角色输出都不应被描述为现实人物对某只股票的当前意见、推荐或交易指令。

本页三个案例全部是界面示例。数值、信号、置信度与评语没有来自实时行情，也不构成投资建议。
数据来源仓库集成多个免费数据源，并支持可选 API；可用性受地区网络、频率限制与标的覆盖影响。
免费回退部分字段可从免费来源回退，但回退不等于数据完整。缺失维度会影响评分质量。
缓存结构流程可缓存 raw_data.json、dimensions.json、panel.json 与 synthesis.json 等中间结果。
数据新鲜度取决于各上游来源更新时间与缓存命中。使用前应核对时间戳及来源状态。
角色与规则66 个角色按字段白名单、规则与提示执行，是“某方法论视角下的评估”，不是人物数字分身。
人数口径当前代码数据库为 66 人、9 组；其中 2 个做空 mandate 角色用于风险观察，不纳入长仓共识分布。
结果限制confidence 表示系统对该次评估的内部置信，不代表收益概率；输出需结合原始数据复核。
