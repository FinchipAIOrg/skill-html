CORE CAPABILITIES

Explicit data operations, not memory magic

Every step emits structured JSON. Every decision can be traced to input, thresholds, and evidence.

Evidence-backed extraction

Every candidate returns its source quote, message index, type, salience breakdown, and ADD / UPDATE / MERGE / SKIP operation.

Explicit memory operations

The existing store participates in similarity checks: duplicates are skipped, related items update or merge, and only durable new information is added.

Loss-aware consolidation

Same-type near duplicates cluster while differences in numbers, versions, identifiers, acronyms, and proper nouns block unsafe merges.

Documented forget policy

KEEP / COMPRESS / DELETE follows value, recency, frequency, sticky floors, TTL, and stale-todo rules with reasons on every item.

Local and reproducible

Python standard library only; no network, API key, or runtime file writes. The same input and now reproduce byte-identical output.

HOW IT WORKS

One inspectable memory lifecycle

No external model call. Input, rules, and now determine the output.

BOUNDARIES

A memory utility, not a human brain

It does not predict future user needs or automatically remember everything.
It does not browse, call an external AI, or persist records to a database.
Similarity and classification are lexical / rule-based heuristics, not a claim of deep semantic understanding.
Compression is subtractive cleanup; it does not add facts, promises, or missing context.
