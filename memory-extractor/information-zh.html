CORE CAPABILITIES

清晰的数据操作，不是黑箱记忆魔法

每一步都产生结构化 JSON；每个决定都能回到输入、阈值与证据。

证据可追溯的提取

每个 candidate 返回原句 quote、消息索引、类型、salience 分解与 ADD / UPDATE / MERGE / SKIP。

显式记忆操作

现有 store 参与相似度判断；重复项跳过，相近项更新或合并，新持久信息才新增。

保守整理

同类型近重复项聚合；数字、版本、标识符、缩写与专名不同会阻止错误合并。

有理由的遗忘

KEEP / COMPRESS / DELETE 由 value、recency、frequency、类型下限、TTL 与 stale todo 规则共同决定。

本地且可复现

Python 标准库实现；不联网、不读 API key、运行时不写文件。相同 input 与 now 的输出可逐字节复现。

HOW IT WORKS

一条可检查的 memory lifecycle

不创建向量库，不调用外部模型。输入、规则和 now 决定输出。

0.25 specificity + 0.35 durability + 0.25 reuse + 0.15 actor
  • Durability bases: identity .95 · constraint .90 · decision .85 · preference .80 · fact .60 · todo .40

0.60 SequenceMatcher + 0.40 Jaccard
  • Duplicate ≥ .90 → SKIP

same type · greedy single-link · threshold ≥ .62

  • Source IDs and character counts remain in output

0.35 value + 0.35 recency + 0.30 frequency

  • Sticky floors: identity 0.60 · constraint 0.60 · decision 0.40 · preference 0.30
  • Unused todo > 30d → DELETE; expired TTL overrides floors
