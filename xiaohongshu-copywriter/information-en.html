CASE 01 · IDEATE

Start from zero: only a topic

REAL RUN / EXIT 0
SCENARIO

The user has a topic, a core value, an audience, a tone, and one personal detail—but no draft yet.

PROMPT

I only have a topic for a Xiaohongshu post: my first solo day trip. Give me three starting directions that show why choosing three stops felt calmer than planning eight, for college students traveling alone for the first time, in a calm and candid tone.

ACTUAL COMMANDpython3 xhs_assistant.py deliverable/assets/runs/en-case-01/input.json
OUTPUT / RESULT

The runtime returns exactly three directions. Because templates are Chinese, English inputs are inserted into Chinese scaffolding without translation or LLM rewriting.
