02 · CAPABILITIES

Fixed rules. Deterministic output.

It is not a full SAST engine and does not claim business-context understanding. Its value is offline execution, repeatability, and a stable result schema for fast security gates.

01 / EVIDENCE

Line-level evidence

Every finding carries path, line, rule_id, category, severity, excerpt, and recommendation.

02 / TRIAGE

Block / Review / Pass

High findings trigger block; Medium-only findings trigger review; otherwise pass.

03 / COVERAGE

Code + config + compliance

Checks code execution, command injection, deserialization, SQL, TLS, crypto, DEBUG, CORS, binding, randomness, and LICENSE.

04 / RUNTIME

Fully offline

Python standard library only; no network, API keys, or filesystem writes.

05 · RELIABILITY

Security boundaries & reliability

Clear limitations are part of a trustworthy security product.

RuntimePython ≥ 3.9stdlib only
NetworkNot requireddisabled
API KeysNot readnone
Filesystem writeNot requirednone
Analysisline-oriented regex heuristicshuman review
Known limitationfalse positives; not full SASTadvisory

Why is the result verifiable?

The rule set is fixed, execution is offline, the schema is stable, and each finding includes path and line evidence. The same input is repeatable. It does not perform deep inter-file dataflow, business-logic, or semantic analysis, so it should not replace a full SAST product or human security review.
