02 · CAPABILITIES

固定规则，确定性输出

它不是全功能 SAST，也不声称理解业务语义；优势是离线、可复现、输出结构稳定，适合做快速安全门。

01 / EVIDENCE

逐行定位

每条 finding 返回 path、line、rule_id、category、severity、excerpt 与 recommendation。

02 / TRIAGE

Block / Review / Pass

High 触发 block；无 High 但有 Medium 触发 review；其余为 pass。

03 / COVERAGE

代码 + 配置 + 合规

覆盖动态执行、命令注入、反序列化、SQL、TLS、弱加密、DEBUG、CORS、监听地址、随机数与 LICENSE。

04 / RUNTIME

完全离线

仅 Python 标准库；无网络、无 API Key、无文件系统写权限。

03 · WORKFLOW

从源码到发布判定，只有一条执行路径

01

内联源码

将每个文件作为 {path, content} 放入 files 数组。

02

逐行规则扫描

固定 regex 规则逐行匹配；部分规则带 guard。

03

结构化 Finding

返回证据、类别、严重性与建议。

04

排序与汇总

按 High → Medium → Low，再按路径和行号排序。

05

发布判定

生成 block / review / pass。

为什么结果可验证？

规则集固定、执行离线、输出字段固定，并且每条发现都带路径与行号；同一输入可重复运行得到相同结构的结果。与此同时，它不会做跨文件数据流、业务逻辑或深层语义分析，因此不能替代专业 SAST 与人工安全评审。
