06

Security boundaries, compatibility, reliability

This section also states the limits. What it does not do matters as much as what it does.

SECURITY · BOUNDARIES
  • You hold the keys.QE_API_KEY and QE_API_SECRET are read from environment variables only, never written to disk or logs.
  • No custody.The Skill forwards instructions only. Funds stay in your exchange account.
  • Disable withdrawal on exchange API keys and set an IP allowlist.
  • Explicit confirmation.Every order action, including placing, modifying, and cancelling, echoes its parameters and waits for your approval.
  • No forecasting.No signals, no strategy, no backtesting, and no return promises.
COMPATIBILITY · COVERAGE
  • Five exchanges covered, with Binance PM and spot accounts handled separately.
  • Python 3 environment with qe-connector and a small dependency set, installed inside your own environment.
  • Conversational interface, no terminal to build and no changes required to your existing script repo.
  • Exportable output, TCA results go to Excel so they fit existing reporting workflows.
BINANCEOKXDERIBITHYPERLIQUIDLTP
RELIABILITY · LIMITS
  • Traceable order ID throughout, with continuous status reporting and a completion notification.
  • Verifiable fills, with maker and taker breakdown, fees, and timestamps per fill.
  • Depends on the QE cloud service, which requires an account and forwards instructions through its API.
  • The market pre-check script calls api.binance.com directly and needs a proxy on restricted networks. Order placement and queries go through the cloud and are unaffected.
  • No risk controls.It checks balance and margin sufficiency only, with no stop-loss or exposure limits.

Before you start

  • Register at quantumexecute.com and create a platform API key. Keep it in environment variables only.
  • Disable withdrawal permission on exchange API keys and configure an IP allowlist.
  • Prepare a Python 3 environment and install qe-connector and its dependencies.
  • On restricted networks, the market pre-check script needs a proxy to reach api.binance.com.
