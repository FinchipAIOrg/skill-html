Offline PowerPoint Render Engine

从结构化 Prompt 到可编辑演示文稿

输入 deck JSON 或受限 Markdown，PPT Generator 会离线编译、渲染并重新打开成品校验。输出不是示意图，而是真实的 .pptx 文件。

真实能力边界：它不调用 LLM 做研究或文案策划；它把你已经提供的内容可靠地转换成 PowerPoint。

Verified Workflow

真实程序如何生成一份 PPT

流程来自仓库中的 ppt_generator.py、deck_schema.py 与 md2pptx_bridge.py。

01 输入

读取一个 JSON 对象；优先使用结构化 deck，也支持受限 Markdown。

02 验证

检查字段、布局、表格尺寸、本地图片路径和内容安全。

03 编译

转换为 FinChip 控制的 md2pptx Markdown 子集。

04 渲染

子进程调用内置 Martin Template，生成真实 PowerPoint。

05 回读校验

重新打开 PPTX，核对页数、空页、表格与本地图片。

Code-Verified Features

代码中真实存在的能力

这里只列出仓库当前版本能够执行和验证的功能。

JSON

结构化 deck 合约

支持 title、section、bullets、two_col、table 与 image_caption 六种布局。

MD

Markdown 便捷输入

标题、要点与 GFM 表格通过确定性规则编译，不调用 LLM。

PPTX

真实可编辑输出

基于内置 Martin Template 和 python-pptx 生成标准 PowerPoint 文件。

CHK

文件回读校验

检查页数、空页、表格行列和本地图片是否真实写入。

FIT

溢出预警

按要点数量、字符数与表格单元格数给出 warning；极端输入会被拒绝。

OFF

离线与安全硬化

禁用 md2pptx 内联代码执行与网络抓取，只接受本地图片路径。

当前限制

theme 字段已保留但尚未生效；所有 deck 使用同一内置模板。Skill 不负责自动研究、自动写内容、生成图表或挑选线上图片。溢出检测是启发式检查，不是像素级排版测量。

Good Fits

适合内容已准备好的演示任务

当结构或数据已经明确，需要稳定输出 PowerPoint 时最合适。

商业策略简报季度回顾研究结果展示课程汇报产品发布提案计划与路线图离线批量生成
